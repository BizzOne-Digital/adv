# CAFBEX — ChatGPT Image Generation Prompts

Use these prompts in ChatGPT (DALL·E).  
**Style lock (paste once at the start of your chat):**

> Create photorealistic editorial photographs for a premium international agricultural organization called CAFBEX (Canada–Africa Farmers Business Exchange). Style: cinematic, natural light, rich greens and warm soil tones, clean composition, no text, no logos, no watermarks, no flags covering faces, no invented government seals. Aspect ratio 16:9 for heroes; 4:3 for content grids. Diverse, respectful portrayal of Canadian and African farming communities. Avoid cartoon, AI-glossy plastic skin, and stock-photo clichés.

Save files as **JPG or WebP** using the exact filenames below into `public/images/...`

---

## Global style tips
- Prefer: aerial farms, greenhouses, hands in soil, grain, irrigation, B2B meetings, conferences, women and youth farmers, modern machinery
- Avoid: poverty stereotypes, fake “Africa as one country”, overused charity-poster looks
- For heroes: wide landscape, space on the **left** for text overlay (slightly softer / less busy left third)

## How to use (quick)
1. Open ChatGPT → start with the **style lock** paragraph  
2. Generate one image at a time with the prompt  
3. Download as JPG  
4. Save to the matching path under `public/images/`  
   Example: `public/images/home/hero.jpg`  
5. Hard refresh the site (`Ctrl+Shift+R`)  
6. Or upload via **Admin → Media** / image fields (MongoDB uploads)

## Recommended generate order (highest impact first)
1. `home/hero.jpg`  
2. `heroes/page-hero.jpg`  
3. `about/hero.jpg` + `about/feature.jpg`  
4. Each `services/*/hero.jpg`  
5. `gallery/*`  
6. Remaining page heroes + grids
