# CAFBEX image placeholders

Replace these SVG placeholders with your own photos.

## How it works

Pages look for images under paths like:

- `/images/about/hero.jpg`
- `/images/about/01.jpg` … `/images/about/05.jpg`
- `/images/services/farmer-connections/01.jpg` … `05.jpg`
- `/images/home/hero.jpg`

Until you add real `.jpg` / `.webp` / `.png` files, the site automatically falls back to matching `.svg` placeholders (branded gradients with a “replace” label).

## Suggested photo themes

- Canadian farms and African farms
- Farmers collaborating
- Greenhouses and modern irrigation
- Agricultural machinery and technology demos
- Crop production and food processing
- Trade exhibitions, conferences, B2B meetings
- Women in agribusiness and youth farmers
- Climate-smart agriculture and export logistics

## Tips

1. Keep the same filenames/folders so you do not need code changes.
2. Prefer WebP or optimized JPEG (1600–2400px wide).
3. After uploading via Admin → Media Library (Cloudinary), you can also set images from the admin editors.
4. Update alt text in admin for accessibility and SEO.
